System Architecture & Topology

                
            

            

                
ResearchMind is a modular multi-agent reasoning swarm orchestrated over FastAPI and LangChain:

                

                    

                        🔍
                        1. Search Agent
                        
Queries Tavily Search API with dynamic relevance ranking to identify high-signal sources.

                    

                    
↓

                    

                        📄
                        2. Reader Agent
                        
Navigates to the most relevant URL and scrapes full body text using BeautifulSoup, cleaning boilerplate scripts.

                    

                    
↓

                    

                        ✍️
                        3. Writer Chain
                        
Synthesizes search intelligence and scraped deep content into a structured research report with citations.

                    

                    
↓

                    

                        🧐
                        4. Critic Chain
                        
Conducts an adversarial audit evaluating factual clarity, structure, and depth, returning actionable feedback and a score.
